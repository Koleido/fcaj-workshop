This section summarizes the activities completed throughout my internship in the **First Cloud AI Journey** program.

The worklog records the objectives, tasks performed, and achievements for each week, providing an overview of my learning progress and project development during the internship. Throughout the program, I gradually explored AWS services, completed guided hands-on activities, developed a cloud-native application, participated in enterprise sharing sessions, contributed technical blog posts to the AWS Study Group community, and prepared the final internship report.

The internship was completed over **eight weeks**, with the following weekly activities:

### **Week 1:** [Getting Started with AWS and Preparing the Learning Environment](1.1-week1/)

Learned the fundamentals of AWS, created an AWS Free Tier account, explored the AWS Management Console and AWS CLI, and launched the first Amazon EC2 instance.

### **Week 2:** [Hands-on Practice with Core AWS Services](1.2-week2/)

Completed several AWS Skill Builder learning activities, practiced Amazon EC2, Amazon RDS, AWS Lambda, and AWS Budgets, and explored Amazon Bedrock.

### **Week 3:** [Researching the Internship Project](1.3-week3/)

Researched cloud-native application architecture, analyzed project requirements, and identified suitable AWS services for the HCMUT Cinema project.

### **Week 4:** [Designing the Cloud Architecture](1.4-week4/)

Designed the system architecture, assigned responsibilities to AWS services, and planned the overall deployment strategy.

### **Week 5:** [Developing the HCMUT Cinema Project](1.5-week5/)

Implemented core project components and integrated AWS services including Amazon S3, EC2, RDS, DynamoDB, and SES.

### **Week 6:** [Reviewing the Project and Preparing Documentation](1.6-week6/)

Reviewed the project architecture, consolidated AWS knowledge, and organized supporting materials for the internship report.

### **Week 7:** [Knowledge Sharing and Enterprise Meeting](1.7-week7/)

Published technical blog posts to the AWS Study Group community, participated in the Enterprise Meeting, and documented the event.

### **Week 8:** [Finalizing the Internship Report](1.8-week8/)

Reviewed the report, organized project documentation, and prepared the final submission package.

> Overall, this worklog reflects both my technical learning journey and the practical experiences gained throughout the First Cloud AI Journey internship program.
