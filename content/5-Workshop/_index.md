# HCMUT Cinema Deployment Workshop on AWS

Welcome to the hands-on deployment workshop. In this section, we will walk through every step to take the **HCMUT Cinema** system from a local development environment to a fully functional, cloud-hosted production environment on AWS.

The deployment process simulates a real-world Production setup with all essential components: Virtual Private Cloud (VPC), Virtual Machine (EC2), Static Hosting (S3), Databases (RDS, DynamoDB), and Automated Email Service (SES).
